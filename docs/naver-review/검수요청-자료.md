# 네이버 로그인 검수 요청 자료 (밀포인트)

네이버 개발자센터 → 내 애플리케이션 → 밀포인트 → **네이버 로그인 검수상태** 탭에서 검수 요청할 때 쓰는 자료입니다.
입력란 이름은 네이버 화면과 조금 다를 수 있으니, 비슷한 항목에 맞춰 넣으세요.

## 1. 요청 전 점검 (API 설정 탭)

| 항목 | 넣을 값 | 상태 |
| --- | --- | --- |
| 서비스 URL | `https://mealpoint.co.kr` | 등록됨 |
| Callback URL | `https://www.mealpoint.co.kr/api/auth/naver?action=callback` | 등록됨 |
| 로고 이미지 | 밀포인트 로고 | 등록됨 |
| 제공 정보 | **이름(필수), 이메일(선택)** 두 가지만 체크 | 확인 필요 |

제공 정보는 실제로 쓰는 항목만 체크해야 합니다. 쓰지 않는 항목(생일, 성별, 휴대전화 등)이 체크돼 있으면 반려 사유가 되므로 해제하세요.

Callback URL 중 `https://lrctaritoeqgliaewpfe.supabase.co/auth/v1/callback`은 현재 쓰지 않는 주소입니다. 지워도 됩니다.

## 2. 서비스 소개 (붙여넣기용)

```text
밀포인트(https://www.mealpoint.co.kr)는 급식 용기·발열도시락 도소매 업체가 운영하는 급식포털입니다.
급식 업체(거래처)가 회원가입 후 사업자등록증을 제출해 승인받으면 업체별 단가로 상품을 조회·주문할 수 있습니다.
네이버 로그인은 회원가입과 로그인을 간편하게 하기 위해 사용합니다.
```

## 3. 제공 정보별 사용 목적 (붙여넣기용)

| 제공 정보 | 필수 여부 | 사용 목적 | 쓰이는 화면 |
| --- | --- | --- | --- |
| 이름 | 필수 | 회원 식별, 업체 담당자 이름으로 표시 | 내 정보(`/account`)의 "담당자 이름", 상단 "○○○님" |
| 이메일 | 선택 | 가입 승인 결과·주문 관련 안내 연락 | 내 정보(`/account`)의 "이메일" |

```text
- 이름: 회원 식별 및 업체 담당자 이름 표시에 사용합니다. 네이버 로그인으로 가입하면 '내 정보' 화면의 담당자 이름에 자동 입력됩니다.
- 이메일: 가입 승인 결과와 주문 관련 안내 연락에 사용합니다. '내 정보' 화면의 이메일에 자동 입력되며 회원이 수정할 수 있습니다.
- 그 외 정보는 받지 않습니다. 수집 항목은 개인정보처리방침(https://www.mealpoint.co.kr/privacy) 2항에 명시돼 있습니다.
```

| `02-회원가입-네이버버튼.png` | 회원가입 화면의 "네이버로 간편 가입" 버튼 | 완료 |

| `04-개인정보처리방침.png` | 개인정보처리방침(소셜 로그인 수집 항목 포함) | 완료 |

### 03번 캡처 방법 (다시 찍을 때 참고)

1. 멤버 관리 탭에서 본인 네이버 아이디를 테스터로 등록합니다(애플리케이션 등록 계정이면 생략).
2. `https://www.mealpoint.co.kr/register` → "네이버로 간편 가입" → 네이버 동의 화면에서 동의합니다.
   - 이때 뜨는 **네이버 동의 화면도 캡처**해 두면 좋습니다(`03-0-동의화면.png`). 요구하는 경우가 있습니다.
3. 가입이 끝나면 내 정보(`/account`) 화면으로 이동합니다. 담당자 이름과 이메일이 채워진 상태로 전체 화면을 캡처합니다.
4. 이 폴더에 `03-내정보-제공정보활용.png`으로 저장합니다.

## 5. 검수 중 유의사항

- 심사자는 실제 사이트에 접속해 네이버 로그인 버튼이 보이는지 확인합니다. 검수가 끝날 때까지 로그인·회원가입 화면의 버튼을 숨기지 마세요.
- 반려되면 사유가 메일과 검수상태 탭에 표시됩니다. 사유에 맞춰 보완한 뒤 다시 요청하면 됩니다.
