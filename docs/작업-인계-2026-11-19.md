### C. 다음 세션에서 할 수 있는 코드 작업

우선순위 순입니다. 각 항목은 서로 독립적입니다.

1. **박스 단가를 그대로 기록** — 코드 완료(2026-11-19), 커밋·배포 전
   - `inventory_logs.amount`(판매 금액, NULL 허용)를 추가했습니다: `supabase/schema-v43-sale-amount.sql`.
     박스 단가가 입수로 나누어떨어지지 않는 판매만 금액을 `amount`에 남기고, 나머지는 NULL(= `quantity * unit_price`)입니다.
   - 금액은 `src/lib/inventory.ts`의 `logAmount()` 하나로 구합니다(판매·정산·손익·대시보드·재고·명세서 불러오기).
     판매 기록의 금액을 새로 계산하는 코드를 쓸 때도 이 함수를 써야 합니다.
   - **배포 순서: 운영 DB에 v43을 먼저 실행한 뒤 푸시합니다.** 컬럼 없이 배포하면 판매·정산·손익·대시보드가 열리지 않습니다.
   - 기존 기록은 바뀌지 않습니다. 이미 50,100원으로 기록된 판매는 판매 관리에서 수정 저장하면 박스 단가대로 고쳐집니다.
   - 입고 화면은 개당 단가를 직접 입력하므로 해당 없습니다.
   - **단가표에도 박스 금액 저장** — 코드 완료(2026-11-19), 커밋·배포 전: `supabase/schema-v44-box-price.sql`
     (`company_prices.box_price`, `company_price_history.box_price`, `products.selling_box_price`, 모두 NULL 허용).
     개당 단가는 그대로 두고 박스 금액을 따로 저장합니다. 비어 있으면 개당 단가 × 입수입니다.
     단가는 `src/lib/box-price.ts`의 `resolveSellPrice()`로 구합니다(판매·명세서·주문·견적).
     입력은 단가 관리(판매가 모드, 개당 단가 아래 "박스" 칸)와 상품 수정(박스 판매가)에서 합니다.
     **v44도 운영 DB에 먼저 실행한 뒤 푸시합니다.**
     거래처 포털 발주는 낱개 단위·개당 단가 그대로입니다(박스 금액 미적용).

2. **명세서 불러오기를 매출 인정 기준과 맞출지 결정**
   - 매출은 체크한 날짜만 인정하지만, `src/app/admin/statements/new/page.tsx`의 불러오기 4곳은
     체크와 무관하게 등록된 판매를 모두 가져옵니다.
   - 사용자 결정이 필요합니다(체크한 판매만 불러올지, 지금처럼 둘지).

3. **로그인 화면의 비밀번호 저장 방식**

   - 아이디만 저장하도록 바꾸는 것이 간단한 방법입니다. 기능이 줄어드므로 사용자 확인 후 진행합니다.

4. **화면 진입 시 데이터 불러오기 방식 (린트 경고 31건)**
   - `react-hooks/set-state-in-effect`를 `eslint.config.mjs`에서 경고로 낮춰 두었습니다.
   - 21건은 `useEffect(() => { fetchData(); }, [])` 형태, 10건은 효과 안에서 상태를 직접 바꾸는 형태입니다.
   - 실제로 고치려면 화면 25개의 데이터 로딩을 다시 짜야 합니다. 화면 몇 개씩 나눠 확인하며 진행해야 합니다.
   - 주의: 함수를 한 겹 감싸면 검사는 통과하지만 동작은 같으므로, 그런 식으로 숨기지 않기로 했습니다.

   - 오래 로그인하지 않은 계정을 조사해 비밀번호 재설정을 요구하는 방법이 있습니다. 운영 DB 조회가 필요합니다.

   - 쓰지 않는 갱신을 없애거나 DB에서 원자적으로 증감하도록 바꿉니다.

## 4. 사용자에게 알려야 할 수 있는 동작 변화

- 관리자가 발급·초기화하는 비밀번호는 8자 이상
- 직접 입력 품목이 있는 견적은 주문으로 전환 불가
- 입출고 이력이 있는 상품은 삭제 불가(판매 중단으로 처리)
- 사업자등록증 크기 한도 4MB
- 무료 체험은 카카오 회원만, 한 번만
- 세금계산서 발행 후에는 청구 금액이 자동으로 바뀌지 않음
- 체크하지 않은 날짜의 판매는 매출에서 제외
- 관리자 본인 계정은 직접 정지·삭제 불가
